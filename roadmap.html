Roadmap

Plans can change. This page separates what is done from what is intended.

1. Learning in progress

Step-by-step lessons and runnable notebooks, in English first and more languages over time.

2. Software in progress

Neuron playground (done). Network playground with raster plots and a float vs fixed-point comparison (first version done). Next: written lessons for both.

3. Hardware planned

Verilog neuron designs on a low-cost iCE40 FPGA, checked against a Python reference.

4. Products long term

Open building blocks for energy-efficient edge AI, sustainable AI and green computing. Not started; this depends on what learning and hardware work shows is useful.

Spiyk is an early, open-source project. Code is MIT licensed; lesson text is CC BY 4.0. Developed with the help of AI tools.
