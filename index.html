Learn neuromorphic computing without expensive hardware

Spiyk builds free, open-source tools and lessons that make brain-inspired computing easy to understand, try and build with. For students, self-taught developers and working engineers, anywhere in the world.

Try the neuron playground See the learning path

Why this exists

Neuromorphic computing could let AI run on a small fraction of today's energy, which matters for edge devices, sustainable AI and green computing. But learning it often needs costly hardware, paid courses or access to a research lab. Many capable people are priced out before they start. Spiyk aims to lower that barrier.

Available today

LIF Neuron Playground live

A browser-based leaky integrate-and-fire neuron simulator. No install; runs on older laptops and phones.

Spiking Network Playground live

50 spiking neurons run twice on the same input, in decimal numbers and in whole-number fixed-point, side by side.
