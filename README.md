# Spiyk

Free, open-source, low-cost tools and lessons for learning neuromorphic computing.

**Website:** https://spiyk.github.io/

## About

Neuromorphic computing could let AI run on a fraction of today's energy, but learning it often needs costly hardware, paid courses or access to a research lab. Spiyk aims to make it easier to understand, try and build with, for students, self-taught developers and working engineers anywhere.

## What is here

This repository contains the source of the Spiyk website: the home page, a step-by-step learning path and the roadmap. Lessons are added only once they are written and tested.

## Related projects

- [LIF Neuron Playground](https://github.com/spiyk/lif-neuron-playground): a browser-based leaky integrate-and-fire neuron simulator
