About Spiyk

Free, open-source, low-cost tools and lessons for learning neuromorphic computing.

Who is behind it

Spiyk is built by Soumen Mukherjee, a programmer learning neuromorphic computing in public. Find me on LinkedIn, Mastodon and GitHub.

Why it exists

Learning neuromorphic computing often needs costly hardware, paid courses or access to a lab. Spiyk aims to lower that barrier with tools that run in a browser and lessons that explain the ideas plainly.

How this site is made

Spiyk is built in the open. The lessons, the playgrounds and the code of this site live in public GitHub repositories, and every change is recorded in their commit history. What matters for readers is how the material is checked.

Corrections and contributions

If something is unclear or wrong, please open an issue on GitHub. Corrections, translations and ideas are welcome. Code is MIT licensed and lesson text is CC BY 4.0.
