Learning path

Eight steps from your first spiking neuron to real hardware, using free tools. Lessons are added as they are written and tested; unfinished ones are not linked.

1. What is neuromorphic computing, and why? lesson ready

Brains versus conventional chips, energy use, where this is used today, and honest limits.

2. The spiking neuron (LIF) lesson ready

Integrate, leak, fire. Read the lesson, then use the interactive playground.

3. Encoding information as spikes lesson ready

Rate coding, temporal coding and event-based data. Pairs with the LIF playground.

4. A small network and the raster plot lesson ready

Connect neurons and read what the network is doing. Pairs with the network playground.

5. Your first model with snnTorch coming soon

Train a small spiking network on free Google Colab. Requires Python basics.

6. Fixed-point and quantization lesson ready

Why hardware uses small integers, and what it costs. Pairs with the network playground.

7. A neuron in Verilog on an iCE40 FPGA coming soon

Write, simulate and run a hardware neuron with open-source tools.

8. The hardware landscape coming soon

Loihi, SpiNNaker, Akida and others: what exists, what is accessible, what is not.

Free resources to use alongside
